# ONE ITSM Portal

Interactive ITSM process portal (Incident · Service Request · Change Request) for the ONE System Environment.

- `index.html` — main portal (Home / Process Maps / Resources) with embedded Lucidchart views
- `process-maps-site.html` — lightweight SR/INC/CR tabbed embed page

## Local preview

```bash
python3 -m http.server 8777
# open http://localhost:8777/
```

Published from the repository root (or `/docs`) on the default branch.
