Core Processes

Three request types, three objectives

Each process has a distinct trigger, workflow, and control model. Click a card to open its full process map.

INC

Incident

Unplanned interruption or reduction in the quality of an IT service.

  • eCom / Portal dashboard loading error
  • OPUS booking RPA halt · EDI failure
  • ERP-BRIM AR interface connection failure
GOAL · Restore service ASAP
Open process map →
SR

Service Request

Formal request from a user for standard information, access, or advice.

  • CHORUS / GCP IAM DB access grant
  • S/W install & PC replacement
  • User manual & master-data guide
GOAL · Fulfill routine request
Open process map →
CR

Change Request

Formal proposal for modifying, adding, or removing IT systems / services.

  • OPUS Booking & BL weekly deployment
  • QueryPie DAC & DB security update
  • New EDI partner interface & firewall
GOAL · Formal proposal for modifying, adding, or improving IT systems / services.
Open process map →
